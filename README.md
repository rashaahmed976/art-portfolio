# 📘 دليل رفع الموقع على GitHub Pages

> دليل خطوة بخطوة بالعربية لرفع معرض إنجازاتك على الإنترنت **مجاناً** بدون أي تكلفة، مع الحصول على دومين مجاني.

---

## 🎯 ما الذي ستحصلين عليه؟

- موقع إلكتروني مجاني تماماً (بدون أي رسوم)
- دومين مجاني بصيغة: `اسم_المستخدم.github.io/art-portfolio`
- استضافة دائمة لا تنتهي
- سرعة عالية وثبات
- إمكانية التعديل في أي وقت

---

## 📋 الخطوات (مرتبة)

### الخطوة 1: إنشاء حساب GitHub

1. افتحي الموقع: https://github.com
2. اضغطي على **Sign up** في أعلى اليمين
3. أدخلي:
   - **Email**: بريدك الإلكتروني
   - **Password**: كلمة مرور قوية
   - **Username**: اسم المستخدم (مثل: `rasha-art-teacher`)
   > ⚠️ مهم: اسم المستخدم سيظهر في رابط موقعك، فاختاريه باسم مهني
4. أكدّي البريد الإلكتروني من خلال الرسالة التي ستصلك

---

### الخطوة 2: إنشاء مستودع (Repository) جديد

1. بعد تسجيل الدخول، اضغطي على **+** في أعلى الصفحة، ثم **New repository**
2. أدخلي:
   - **Repository name**: `art-portfolio` (مهم: اسم اللاتيني فقط)
   - **Description**: `معرض إنجازات قسم التربية الفنية`
   - اختاري **Public** (مهم جداً ليعمل الموقع المجاني)
   - ضعي علامة ✅ على **Add a README file**
3. اضغطي **Create repository**

---

### الخطوة 3: رفع ملفات الموقع

#### الطريقة الأسهل (السحب والإفلات):

1. ادخلي إلى المستودع الذي أنشأتيه
2. اضغطي على **Add file** ← **Upload files**
3. اسحبي **كل محتويات مجلد `website`** (الملفات والمجلدات معاً):
   - `index.html`
   - مجلد `pages/`
   - مجلد `assets/`
4. في خانة **Commit changes** اكتبي: `إضافة ملفات الموقع`
5. اضغطي **Commit changes**

---

### الخطوة 4: تفعيل GitHub Pages

1. في صفحة المستودع، اضغطي على **Settings** (في الشريط العلوي)
2. من القائمة الجانبية، اضغطي على **Pages**
3. تحت **Source**، اختاري:
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. اضغطي **Save**
5. انتظري دقيقة إلى دقيقتين، ثم ستظهر رسالة:
   > **Your site is live at:** `https://YOUR-USERNAME.github.io/art-portfolio/`

🎉 **مبروك! الموقع أصبح متاحاً على الإنترنت!**

---

### الخطوة 5: تحديث الروابط في ملف PowerPoint

في ملف العرض التقديمي، الروابط تشير حالياً إلى:
```
https://YOUR-USERNAME.github.io/art-portfolio/...
```

تحتاجين استبدال `YOUR-USERNAME` باسم المستخدم الحقيقي:

1. افتحي ملف `presentation_final.pptx`
2. اضغطي **Ctrl+H** (Find and Replace)
3. في خانة **Find**: `YOUR-USERNAME`
4. في خانة **Replace**: اسم المستخدم على GitHub (مثلاً: `rasha-art-teacher`)
5. اضغطي **Replace All**
6. احفظي الملف

---

## 📁 كيف ترفعين الصور والفيديوهات لاحقاً؟

كل صفحة من الـ 19 صفحة لها مجلد مخصص. لإضافة محتوى:

### إضافة صور:
1. اذهبي إلى مستودعك على GitHub
2. ادخلي مجلد `assets/images/`
3. أنشئي مجلد جديد باسم رمز الكفاءة (مثلاً: `1-1` للكفاءة 1.1)
4. ارفعي الصور فيه (PNG, JPG)
5. افتحي ملف الصفحة المقابلة (مثلاً: `pages/1-1.html`)
6. ابحثي عن قسم `<div class="gallery">` وأضيفي:
```html
<img src="../assets/images/1-1/photo1.jpg" alt="عمل فني 1">
<img src="../assets/images/1-1/photo2.jpg" alt="عمل فني 2">
```

### إضافة فيديوهات:
- **خيار 1 (موصى به)**: ارفعي الفيديو على YouTube (سراً/غير مدرج) ثم ضعي رابط embed:
```html
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allowfullscreen></iframe>
```
- **خيار 2**: ارفعي الفيديو مباشرة (للملفات الصغيرة فقط أقل من 25MB):
```html
<video controls width="100%">
    <source src="../assets/videos/1-1/video1.mp4" type="video/mp4">
</video>
```

### إضافة ملفات PDF أو Word:
1. ارفعي الملف في `assets/files/[رقم الكفاءة]/`
2. في صفحة HTML المقابلة، أضيفي رابط:
```html
<a href="../assets/files/1-1/خطة_درس.pdf" class="file-item" target="_blank">
    <span class="file-icon">PDF</span>
    <span>خطة درس - الزخارف الإسلامية</span>
</a>
```

## 🛠️ كيف تعدّلين النصوص في الصفحات؟

1. اذهبي للمستودع على GitHub
2. ادخلي مجلد `pages/`
3. اضغطي على الملف الذي تريدين تعديله (مثلاً: `1-1.html`)
4. اضغطي على أيقونة **القلم ✏️** في أعلى اليمين
5. عدّلي النص داخل وسوم `<p>...</p>` في قسم `achievement-description`
6. اضغطي **Commit changes** للحفظ
7. التغييرات ستظهر على الموقع خلال دقيقة

---

## ❓ أسئلة شائعة

**س: هل الموقع مجاني فعلاً؟**  
ج: نعم 100%. GitHub Pages مجاني للمشاريع العامة (Public)، بدون أي رسوم أو حدود زمنية.

**س: هل يمكن استخدام دومين خاص لاحقاً؟**  
ج: نعم، يمكنك ربط دومين خاص (مثل `rashaart.com`) إذا اشتريتيه لاحقاً، لكن الدومين المجاني كافي تماماً.

**س: ما حد حجم الملفات؟**  
ج: 1GB لكل مستودع، وملف واحد بحد أقصى 100MB. للفيديوهات الكبيرة، استخدمي YouTube.

**س: هل يمكنني حذف الموقع لاحقاً؟**  
ج: نعم، فقط احذفي المستودع أو أوقفي GitHub Pages من الإعدادات.

**س: هل المحتوى آمن؟**  
ج: المحتوى عام (Public) ويمكن لأي شخص رؤيته. لا ترفعي معلومات حساسة أو صور خاصة بالطلاب دون إذن.

## 📞 خطوة إضافية: اختبار العرض التقديمي

1. افتحي ملف `presentation_final.pptx`
2. اضغطي **F5** لبدء العرض
3. اضغطي على أي زر "رابط اثرائي" في أي شريحة
4. يجب أن تفتح الصفحة المقابلة على متصفح الإنترنت

✅ إذا اشتغل الرابط، يعني كل شيء تمام!  
❌ إذا ظهرت صفحة 404، تأكدي من:
- اسم المستخدم الصحيح في الرابط
- أن المستودع باسم `art-portfolio` بالضبط
- تفعيل GitHub Pages من الإعدادات
